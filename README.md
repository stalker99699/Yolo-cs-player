# Yolo-cs-player

Репозиторий содержит обученные веса YOLO-модели для детекции игроков в Counter-Strike 2.
> (обучены на видеокарте https://github.com/kiberdans большое спасибо)
> (демка https://youtu.be/0ged8a3-Jm0?si=XJ3iDUnCGBxHMg5y)
## 📊 О модели

- **Датасет:** 1417 изображений (карты Dust2, Mirage).
- **Классы детекции:** 1 класс (`player`).
- **Формат ввода:** HD (под 4:3 в HD разрешении).
- **Архитектура:** Модифицированная YOLO-архитектура с внедрением механизмов внимания (Attention blocks), C2f-модулями и SPPF.

## 📦 Файлы моделей

| Файл | Назначение | Особенности |
|------|------------|-------------|
| `yolo-1417-cs-player.onnx` | **Для CPU** | Оптимизирована для инференса на процессоре. Идеально подходит для скриптов автопилота/триггерботов без видеокарты. |
| `yolo-1417-cs-player.pt` | **Для GPU (и CPU)** | Исходный формат PyTorch. Требует видеокарту для быстрого инференса, но также может работать на CPU. |

## 🧠 Архитектура

Модель базируется на архитектуре YOLO с улучшенным Head'ом:
- **Backbone:** Извлечение признаков с использованием каскадных сверточных блоков и C2f-модулей.
- **Neck (FPN/PAN):** Пирамида признаков для эффективной детекции объектов на разных масштабах.
- **Head (Detect):** Голова детектора использует трансформерные блоки (Attention, MatMul, Softmax) и DFL (Distribution Focal Loss) для более точного предсказания ограничивающих рамок (bounding boxes).

## 🚀 Как использовать

### Инференс через Ultralytics (PyTorch)
```python
from ultralytics import YOLO

# Загрузка модели
model = YOLO('yolo-1417-cs-player.pt')

# Инференс (device=0 для GPU, device='cpu' для CPU)
results = model('image.jpg', device=0) 
results[0].show()
